# مكتب سرهاد

موقع عربي متجاوب لمكتب سرهاد في قرية بوزان، القوش، تلكيف، نينوى.

## المزايا

- دليل الخدمات مع تصفية الأقسام.
- صور كاملة بنسبها الأصلية، مع التكبير والتمرير للملصقات الطويلة.
- أرقام اتصال مباشرة وخريطة المكتب على Google Maps.
- دعم العربية والاتجاه RTL ولوحة المفاتيح وتقليل الحركة.
- لا توجد عملية شراء أو معالجة مدفوعات أو جمع بيانات عبر الموقع.

المعلومات والصور مقدمة من صاحب الموقع. يُرجى التواصل مع المكتب لمعرفة الأسعار والتوفر وساعات العمل.

## التشغيل

الموقع ثابت ولا يحتاج إلى تثبيت حزم أو عملية بناء. افتح index.html، أو قدّم المجلد باستخدام خادم ملفات محلي.
